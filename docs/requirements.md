# Agreed consolidation

The owner approved a new public `KirillSachkov/agent-kit` combining Agent Harness and Agent Clarity, with engineering/communication skills, harness examples and an installer. Source repositories are archived only after history preservation and consumer updates. This is library consolidation, not authorization to implement the retained experimental board work.

## Acceptance

1. One canonical folder per skill under `skills/engineering` or `skills/communication`. Preserve all 28 engineering and four communication skills, whole-folder resources and licenses. `explain` retains its internal/WIP status.
2. Retain both source Git histories, original object IDs, and all existing public branches. The original main heads are ancestors of the consolidated main; unmerged experiments remain named historical branches.
3. The harness example retains its own start authority, worktree, testing and owner-acceptance policy. Library policy and target-project policy remain separate.
4. A client-neutral installer selects immutable versions, previews without writes, preserves complete folders and notices, refuses local modifications and unsafe paths, and explicitly adopts only exact existing copies. Selection preserves unrelated project configuration and client skills.
5. A private Home can use one pinned public provider with grouped offline snapshots. Public source contains no private home data or account configuration.
6. Check canonical catalog/discovery, source identity and provenance, installation behavior, the harness example and communication builds. Commit and independently review Standards and Spec before first public push.
7. Transfer the original public open issue without changing its requirements, retain old URLs and archive the two old repositories after verified publication and controlled consumer switching. Preserve local active work and intentional consumer variants.
