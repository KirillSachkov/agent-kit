# Пример глобальных инструкций

В глобальных инструкциях можно закрепить личные договорённости, которые действуют в разных проектах. Например, в `~/.codex/AGENTS.md` или `~/.claude/CLAUDE.md`.

```markdown
## Communication

- Reply in Russian. If I write in another language, match it.
- Start with the answer or outcome. Explain in detail when I ask.
- For work with several phases, send a short update at the start, when the phase changes, and when the work is done.
```
