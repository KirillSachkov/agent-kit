# Project instructions

Read [project settings](docs/agents/project-settings.md) for the authorized start, working
context, practice choices and delivery authority. Read the [workflow](WORKFLOW.md) for the
rules that connect skills here. A standalone question ends with its answer.
Before choosing tests, read the [testing strategy](@@testing_file@@) and take the seam from it. When it has none for this kind of change, ask the owner once and record the answer there.
When a skill names another skill, load it with your client's skill mechanism, or read its `SKILL.md` when the client has none.
Human-invoked skills run only when the owner names them: never read their files to follow them yourself. When the next step is such a skill, end the reply with its command. The owner's approval answers the current step of the active skill and starts nothing else.
